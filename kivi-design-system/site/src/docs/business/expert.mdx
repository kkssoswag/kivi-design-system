## 参数

专家的数据结构 `ExpertItem`：`id`、`name`、`description`（定位）、`avatar`（头像）、`skills`（预置技能，`SkillItem[]`，用户不能增删）、`strengths`（擅长）、`examples`（试试这样说，最多 3 条）。第一个一般是通用专家（默认，不挂预置技能）。擅长、示例提问、预置技能都没有的专家没有详情（`hasExpertDetail`）。专家都在管理后台配，组件库不带。

### ExpertBar

放在 Agent 输入框工具条里（主站在「Agent」右边，画布在最前面）。触发器就是无底 Select（`variant="plain"`），和工具条别的入口一样：圆头像 16（Avatar，`leftAvatar`）+ 名字 + 向下箭头。点开选择浮层（Menu 单选，宽 320，两行，说明不省略、放不下换行（`wrap`），当前项铺选中底色、不打勾（`mark="fill"`），悬停有详情的专家右边出文字按钮「详情」（Button 28 · 无底灰））。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `experts` | `ExpertItem[]` | — | 必填。能选的专家，第一个一般是通用专家 |
| `value` / `defaultValue` / `onValueChange` | `string` / `string` / `(id) => void` | — / 第一个 / — | 当前专家 |
| `onDetail` | `(expert) => void` | — | 选择浮层里点「详情」，先关浮层再调用 |
| `placement` | `"top-start"` `"bottom-start"` | `"top-start"` | 浮层往哪边弹：贴底的输入框往上，创作首页往下 |
| `disabled` | `boolean` | `false` | Agent 回复进行中：不能换专家 |

### ExpertCard

横条：高 64、圆角 12、Container Light 2 底、不加描边，悬停 Light 2 悬停；左内边距 16，名字 14 中粗一行省略 + 向右箭头 16 tertiary，间距 4；配图铺在右边 112 宽、铺满高、往左渐隐。邀请了描边 border-strong。整条是一个按钮，点了打开详情。其余原生 `<button>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `name` | `string` | — | 必填。专家名字 |
| `avatar` | `string` | — | 配图（专家头像） |
| `invited` | `boolean` | `false` | 已邀请：描边变亮 |

### ExpertDetail

Dialog 800。标题栏是头像 72（AssetThumb）+ 右边名字 20 / 28 中粗、定位 14 / 22 secondary（间距 4，整块和头像上下居中），关闭在右上；底栏靠右 Button 36（没邀请是主要「邀请」，邀请了是次要灰「已邀请」）。中间两块，各有 13 中粗 secondary 小标题、离上面 24：试试这样说（一排三张，间距 8；卡片 1 的弱描边 border-subtle、不铺底、圆角 12、内边距 16：对话图标 Message 16 tertiary 在左、和第一行字对齐，间距 8，字 14 / 22 最多三行；悬停铺 Light 2 悬停）、技能（n）（一位专家一般七八个；两列卡片，1 的弱描边、不铺底、圆角 12、内边距 12：封面 72（AssetThumb，没封面用技能占位封面）+ 名字 14 中粗 + 说明 13 / 20 tertiary 两行，只读）。擅长先不显示（和定位重复）。没有的块不显示。其余属性传给 Dialog。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `open` / `onOpenChange` | `boolean` / `(open) => void` | — | 同 Dialog |
| `name` / `description` / `avatar` | `string` | — | 名字、定位、头像 |
| `strengths` | `string[]` | `[]` | 擅长 |
| `examples` | `string[]` | `[]` | 试试这样说，最多显示 3 条 |
| `skills` | `SkillItem[]` | `[]` | 预置技能，只读 |
| `invited` / `onInvitedChange` | `boolean` / `(invited) => void` | `false` / — | 邀请、取消邀请（回到通用专家） |
| `onExample` | `(text) => void` | — | 点一条示例提问：邀请这位专家、关弹窗、把这句话填进输入框（不发送） |

### ExpertRecord

一行，两边 1 宽的细线（border-subtle），中间头像 16（AssetThumb，没有就不放）+ 文字 12 tertiary，间距 6，线和字间距 12。其余原生 `<div>` 属性都能传。

| 属性 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `avatar` | `string` | — | 专家头像图 |
| `children` | `ReactNode` | — | 必填。「XX 加入对话」「已切换为 XX」 |
